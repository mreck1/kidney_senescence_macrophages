# CSF-1 inhibits senescence and scarring in injured prematurely-aged kidneys by reversing senescence-induced loss of macrophage MerTK

This repository contains scripts to reproduce figures found in the article "CSF-1 inhibits senescence and scarring in injured prematurely-aged kidneys by reversing senescence-induced loss of macrophage MerTK" (Cell Rep. 2026).

Required datasets can be found on GEO under the accession numbers: GSE296922, GSE252584.
